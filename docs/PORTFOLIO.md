## Описание ReserveHub для портфолио

ReserveHub — учебный backend для бронирования оборудования на Java и Spring Boot. В нём реализованы REST API, роли пользователей, каталог, резервирование, выдача и возврат оборудования, история операций и SQL-отчётность. Данные сохраняются через Spring JDBC; миграции выполняет Flyway. Транзакции и блокировки защищают остатки при одновременных запросах. JUnit-тесты проверяют бизнес-правила, доступ к данным и конкурентные операции.

Hibernate ORM в реализации не используется; текущая архитектура — монолит с разделением по предметным областям.
